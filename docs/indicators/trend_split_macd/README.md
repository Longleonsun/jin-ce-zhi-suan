# 趋势分离 MACD 指标（通达信 / 富途）

用日线 MA50 把行情分成上涨区和下跌区，两个区各用一套 MACD 买卖规则：

| 区间 | 判断 | 买入 | 卖出 |
|---|---|---|---|
| 上涨区 | 收盘价在 MA50 上方 | 快速 MACD(6,13,9) 金叉 | 慢速 MACD(24,52,9) 死叉 |
| 下跌区 | 收盘价在 MA50 下方 | 默认 MACD(12,26,9) 金叉 | 快速 MACD 处于死叉状态 |

- 空仓时遇到买点买入，持仓时遇到卖点卖出；同一根 K 线同时出现买点和卖点时以卖点为准。
- 信号在 K 线收盘后确认，按次日开盘执行理解。
- 参数事先固定，没有在任何数据上调过。

## 文件

| 文件 | 用途 |
|---|---|
| `通达信_主图.txt` | 叠加在 K 线上：MA50 黄线，买入点红色箭头和 B，卖出点绿色箭头和 S |
| `通达信_副图.txt` | 红柱表示持有，黄色虚线表示处于上涨区 |
| `通达信_交易系统.txt` | 通达信自带的交易系统测试用 |
| `富途_主图.txt` | 同通达信主图，只用文字标记 B/S（富途图标编号与通达信不同） |
| `富途_副图.txt` | 同通达信副图 |
| `项目回测导入版.txt` | 导入本项目回测；最后一行输出持仓状态 |

各版本的计算部分完全相同，已用项目的通达信公式转换器编译，并在 4 只 ETF 上与独立实现逐根 K 线比对一致。

## 使用方法

**通达信**
1. 打开公式管理器（`Ctrl+F`），在"技术指标公式"下新建。
2. 粘贴对应文件的全部内容。主图版的画线方法选"主图叠加"，副图版选"副图"。
3. 测试公式通过后保存，在 K 线图上调出该指标。
4. 交易系统版在"交易系统公式"下新建，再用通达信的交易系统测试功能评测。

**富途**
1. 进入个股的日 K 图，打开"指标管理"，新建指标。
2. 粘贴对应文件的全部内容，在指标属性里选择主图或副图，保存。
3. 如果编译报错，把错误提示发给我，我再调整。富途支持的函数与通达信大体相同，但个别画图函数可能有差异。

**本项目回测**
在操作工作台的通达信公式转换里导入 `项目回测导入版.txt`，K 线周期选日线；也可以调用 `POST /api/tdx/import_strategy`。回测报告会附带与同期持有的对比和上涨区捕获率。

## 注意

- **用于日线图。** 在分钟图上，`MA(C,50)` 是 50 根分钟 K 线，不是日线 MA50，MACD 也按分钟 K 线计算。要在分钟图上近似日线 MA50，可以把第一行的 50 换成"每天 K 线数 × 50"。例如 A 股 30 分钟图每天 8 根，换成 400；美股 30 分钟图每天 13 根，换成 650。
- **回测导入版的公式必须保留括号。** 项目转换器会把 `AND` 转成 Python 的 `&`，它的优先级比比较运算高，去掉括号会算错。
- **效果参考。** 在 14 只 A股/港股/美股 ETF 的日线上（2018–2026），这套规则的平均年化为 1.35%，同期持有为 4.59%，默认 MACD 为 2.61%。看图时容易只记住漂亮的信号，判断有没有效请以回测数据为准。
