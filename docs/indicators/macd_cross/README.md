# MACD 金叉死叉指标（富途）

对应项目里的 15 号策略：空仓时 DIF 上穿 DEA（金叉）买入，持仓时 DIF 下穿 DEA（死叉）卖出。
金叉和死叉总是交替出现，所以 DIF 在 DEA 上方的时段就是持有期。

| 文件 | 用途 |
|---|---|
| `富途_主图.txt` | 在 K 线上标 B（金叉）和 S（死叉） |
| `富途_副图.txt` | DIF 白线、DEA 黄线、红绿柱，交叉处标 B/S |

## 添加步骤
1. 进入个股 K 线图，打开「指标管理」，新建指标，粘贴对应文件的全部内容。
2. 在「参数设置」里添加三个参数（名称必须与公式一致）：

   | 参数名 | 默认值 | 最小值 | 最大值 |
   |---|---|---|---|
   | FAST | 3 | 1 | 100 |
   | SLOW | 6 | 2 | 200 |
   | SIG | 5 | 1 | 100 |

3. 指标属性里，主图版选「主图」，副图版选「副图」，保存。
4. 以后在指标参数里直接改数字即可试不同参数，FAST 要小于 SLOW。

## 注意
- 参数越短信号越多：3/6/5 在日线上大约每个多月进出一次，震荡时容易来回打脸；常用的 12/26/9 信号少得多。
- 在图上挑出"看起来最好"的参数很容易，但那只是对过去这段走势的拟合。换参数后，建议把同样的参数写进项目配置
  `strategy_params."15"`（`fast_period`、`slow_period`、`signal_period`）回测一次，
  看报告里"与同期持有对比"和上涨区捕获率是否真的更好。
